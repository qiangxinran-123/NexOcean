# 网页与千问办公任务交接约定

## 责任边界

网页负责：产品录入、基础字段验证、状态展示、任务输入复制 / 下载、消息交互与结果展示。

千问办公负责：准入判断、法规解析、真实成本测算与风险分析。网页不实现本地核心业务引擎，也不自行给正式业务结论。本次不做报告或 PDF。

当前只实现手动交接。没有真实 API、模型调用、法规采集或结果自动导入，不宣称已经联通千问办公。

## 当前交接输入

评估页面和成本页面提供“交给千问办公”按钮。可复制任务输入或下载 JSON：

```json
{
  "handoffType": "QWEN_WORK_CORE_TASK",
  "task": "产品市场准入与法规依据评估",
  "createdAt": "ISO8601",
  "product": {
    "name": "用户填写的产品名称",
    "category": "食品饮料",
    "hs": "用户填写的编码，未经核验",
    "market": "中国台湾地区",
    "origin": "中国大陆",
    "specs": "用户填写的产品参数"
  },
  "officialLookupEntries": [{ "name": "机构名称", "url": "官方查询入口" }]
}
```

成本任务额外提供 costInputs、currency（CNY）与 taxRatesAreUnverifiedUserAssumptions（true）。演示场景、演示准入结论和展示金额不进入交接输入。

## 建议与核心任务负责人对齐的输出字段

下面只是网页展示格式建议，不定义核心算法。

- 准入结果：状态、结论说明、申请主体、材料清单、时间信息、待补充字段、具体法规来源、规则版本、生成时间、Session ID。
- 成本结果：分项名称、金额、币种、计算说明、总价、单位成本、未计入项目、数据来源、生成时间、Session ID。
- 法规事件：标题、变更摘要、关联产品、影响说明、来源、生效日期。

只有官方网站首页的结果，不能被展示为已经绑定具体法规条款。缺失项、未知状态与演示标识必须在网页中保留，不静默填充为零或允许。

## 之后若接入 API

先确认实际千问办公产品支持的工作流调用 / 输出方式，不把办公产品直接等同于模型 API。鉴权密钥留在服务端；前端仅提交输入和展示结果。具体接口由千问办公核心任务负责人提供，当前网页不附带后端实现。

保留任务对话、核心产物与 Session ID，清楚记录本网页是第三方工具辅助开发的前端。
