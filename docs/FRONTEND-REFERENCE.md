# 比赛作品前端改版 · 2026-10-11

参考：https://www.aotsea.com/#products（TuringFlow 图灵环流）。

借鉴其产品区的三个展示思路：围绕业务目标组织工具、通过协同链路解释工具关系、明确每个环节的交付产物。沿用知海 TradePilot 的蓝色与琥珀色，以及已有产品、路由和功能。

## 本次前端改动

- 首页主视觉改为「从一个产品，到一份出海方案」，串联准入、成本与增长三个问题。
- 右侧流程示意绑定当前产品，点击阶段与下方工具选项卡联动；示意不表示任务已执行或已完成。
- 工具矩阵按阶段展示 9 个现有入口，说明用途与预期产出；结果、数据覆盖与核验状态在原有工具页面查看。
- 侧栏按工作空间、准入与成本、市场与增长、规则与依据分组，保留全部 11 个页面。
- 增加选项卡键盘操作、可见焦点、触摸尺寸和减少动态效果支持，适配桌面与手机。

## 分工边界

此次只修改 `src/main.jsx` 的首页和导航展示，新增 `src/workflow-showcase.jsx`、`src/workflow-showcase.css`，并重新生成根目录 `dist`。

准入判断、税费计算、法规规则、API、数据存储和任务执行逻辑由千问负责。本次未修改 `tradepilot-core`、`src/qw-client.mjs`、`src/demo-data.mjs` 或海报生成逻辑，也未增加任务自动执行或结果导入能力。

根目录 `index.html` 与 `dist/index.html` 是本次更新的前端预览入口；`tradepilot-core/web` 未更新，线上部署需按现有前端交付流程接入新构建产物。

验证截图和前端检查位于 `tmp/redesign` 与 `tmp/check-redesign.mjs`。
