# 知海 TradePilot · 企业出海网页原型

React 可交互网页，采用现有 Ops Console 的蓝色 / 琥珀色规范，支持电脑与手机。

**交付范围仅为网页。核心准入判断、法规解析、真实成本测算交给千问办公；报告、PDF、后台业务引擎不在本次范围。**

## 打开

直接在浏览器打开根目录的 `index.html`，也可以打开 `dist/index.html`。两种入口均使用已构建的 React、图标和样式，不依赖 CDN，可离线访问。部署时上传整个 `dist` 文件夹即可。

开发环境需要 Node.js 20+：

```sh
pnpm install
pnpm dev
```

访问 http://127.0.0.1:4173 。修改源码后重新启动或运行构建；当前轻量服务器不提供热更新。也可使用 npm install / npm run dev。

```sh
pnpm build       # 构建 dist，适合静态部署
pnpm test        # 浏览器交互检查
pnpm check:ui    # 同上，需本机 Edge / Chrome 或 Playwright Chromium
```

## 五个页面

1. **出海工作台**：产品档案、待处理产品、一期目标市场和待核验来源；提供完整流程入口。
2. **准入评估**：产品信息、模拟状态、待核验事项、办理路径、官方查询入口与任务交接。
3. **成本页面**：参数录入、两组固定结果示例、模拟情景切换；修改参数后等待千问办公测算，网页不在本地算税。
4. **法规预警**：手动模拟变更、关联产品、未读 / 已读状态。
5. **产品档案**：新增、编辑、关键词搜索、准入状态筛选、本地保存。

## 千问办公交接

评估与成本页提供“交给千问办公”按钮，可复制或下载输入 JSON。输入包含用户产品资料、成本参数及官方查询入口，不包含模拟场景和演示结论。

当前为手动交接，未接通千问办公 API，也未实现结果自动导入。后续由核心任务负责人提供实际产物格式 / 工作流调用方式，再做前端展示对接。参赛用的核心产物与 Session ID 在千问办公保留。

## 演示边界

- 准入状态、税率、金额与法规变更全部是固定展示样例，不用于真实贸易决策。
- 新产品默认“无法判定”，演示状态由用户明确选择；编码、原产地和产品参数不触发真实准入判断。
- 官方链接只提供查询入口，不表示已经完成具体法规条款核验。
- 成本页面不执行税费计算，只有两组固定快照。输入变化后隐藏样例金额，转为任务交接提示。
- 产品与消息数据保存在当前浏览器 localStorage。没有登录、云同步、企业数据隔离或采集后台。
- 本项目不提供报告中心、报告内容生成或 PDF 导出。

## 一周内网页工作安排

| 天 | 网页工作 |
|---|---|
| 1 | 用本原型确认页面结构、配色与演示流程 |
| 2 | 与千问办公负责人对齐输入 / 输出字段 |
| 3 | 完善录入、校验、加载、空状态和错误状态 |
| 4 | 根据实际工作流能力对接结果展示，不代做核心任务 |
| 5 | 验证任务交接、来源展示与手机操作 |
| 6 | 部署网页，准备访问说明，修复测试问题 |
| 7 | 配合团队录制网页真实操作，提供前端开发截图 |

## 文件

- `src/main.jsx`：五个页面、表单、任务交接与交互。
- `src/styles.css`：设计变量、响应式布局、减少动态效果。
- `src/demo-data.mjs`：固定样例、字段验证及浏览器存储；不含核心业务引擎。
- `scripts/`：构建、本地服务器、浏览器验证。
- `docs/API-CONTRACT.md`：网页与千问办公的任务交接约定。

原有 `_pst` 与 `_skilltmp` 未修改。
