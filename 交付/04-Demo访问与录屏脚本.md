# Demo 访问说明与 3–5 分钟录屏脚本

## 一、访问方式

**公网 Demo**：https://uqpmn9fs.qwenwork.host/

- 无需登录、无需安装、无需配置。手机端与电脑端均可访问。
- 打开后右上角会显示运行模式徽章：`服务端引擎 · LLM 模板降级 · jsonfile` 表示后端可用；
  若显示 `本地引擎模式（浏览器内计算）`，说明后端接口不可达，前端会自动降级为浏览器内运行同一套引擎
  ——**两种模式产出的结论完全一致**，因为调用的是同一份引擎源码。
- 数据保存说明：演示环境为服务端文件存储，实例重启后档案与记录会清空，录屏前建议先点
  「产品档案 → 载入 3 个示例产品」。

**本地运行**（评审如需源码验证）：

```sh
cd tradepilot-core
node server.js                     # http://127.0.0.1:8081，零依赖，无需 npm install
node --test tests/engine.test.mjs  # 27 项引擎断言
node tests/api-smoke.mjs           # 36 项接口冒烟（自带起停）
node tests/ui-check.mjs            # 28 项真实浏览器端到端（需 Playwright + Edge/Chrome）
```

## 二、录屏分镜（建议 4 分 20 秒，全部为真实操作，不用 PPT）

| 时间 | 操作 | 要讲的话（对应评审维度） |
|---|---|---|
| 0:00–0:25 | 打开首页，展示工作台与常驻免责声明 | 痛点来自真实访谈：卡点不是营销，是准入不确定、合规风险、关税隐性成本与信息差 |
| 0:25–1:15 | 点「准入评估」→ 输入 HS 220299／大陆产地／中国台湾地区 → 开始判定 | 展示结论、申请主体（大陆厂商不可自行申报，必须当地进口商）、办理路径 5 项制度、17 项书件、关键路径区间 |
| 1:15–1:40 | 勾选「宣称保健功效」重新判定 | **亮点**：结论自动从"有条件准许"升级为"需专案核准"，并给出"改写文案 vs 申请健康食品认证"两条路径的成本指数与周期对照 |
| 1:40–2:00 | 把 HS 改成 999999 再判定 | **亮点**：系统输出"无法判定"而不是猜——这是防幻觉的产品化，宁可无用不可编造 |
| 2:00–2:45 | 「成本测算」→ 170199 糖 → 开始测算 | 展示分项计算式（每行都能手算复核）、综合税负率、含 SSG 缓冲与汇率缓冲的报价带、未计入项清单 |
| 2:45–3:10 | 点「多方案对比」 | 同一产品跨口岸跨数量跨 SSG 情景的矩阵，最优/最差与价差百分比，风险标记 |
| 3:10–3:40 | 「SSG 预警」→ 选磁砖 → 计算 | 累积量已达触发点 95%，本批会直接触发；展示触发后单件成本上涨模拟与报价缓冲建议 |
| 3:40–4:05 | 「标签合规校验」→ 直接点扫描 | 简体文案命中繁体词库（繁简归一）、医疗效能宣称、绝对化用语、零添加、产地表述、华人圈话术，逐条给依据与改写方向 |
| 4:05–4:20 | 「规则知识库后台」→ 打开一条税则编辑 | 强调运营人工核验不可省略；未核验规则会让结论自动降级为"参考级"并显示警告 |

**收尾一句话**：所有数字都来自规则库推导，大模型只负责把结论写成摘要，且输出前要通过数字白名单审计——
文本里出现的每个数字都必须在引擎结果里找得到，否则整段作废并降级为模板成文。

## 三、可提交的辅助材料

- 运行截图 13 张：`tradepilot-core/docs/screenshots/`（由端到端检查自动生成，含移动端与降级模式）

## 四、录屏注意事项

- 视频以真实产品操作为主，不能仅用 PPT 讲解；MP4 格式，单个不超过 500MB，最多 2 个。
- 画面中出现的税率与结论均带"待核验"徽章，**不要剪辑掉**，这恰好是作品诚实性的证据。
- 提交前确认已按要求发布带指定话题的分享内容，并把链接填入作品提交页。
