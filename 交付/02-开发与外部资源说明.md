## 一、第三方工具使用情况（如实说明）

| 工具 | 承担部分 | 是否属于核心产物 |
|---|---|---|
| ChatGPT | 前端毛坯房：页面结构、蓝/琥珀视觉规范、五个页面的交互骨架、`docs/API-CONTRACT.md` 交接契约。其 README 明确声明"核心准入判断、法规解析、真实成本测算交给千问办公，网页不实现本地业务引擎" | 否（辅助） |
| 千问办公 | **全部核心业务逻辑**：规则知识库与检索层、准入判断引擎、综合税负引擎、SSG 监控引擎、标签合规引擎、法规变更影响评估、多方案对比、大模型网关（prompt 版本/限流/日志/费用/数字白名单审计/降级）、双模仓储、零依赖 Node 服务端、报告导出、前端与引擎共用的零构建实现、91 项自动化验证 | 是 |
| Playwright + 本机 Microsoft Edge | 端到端验证与运行截图采集 | 否（测试工具） |
| Node.js 22（便携版，免安装） | 本地运行与语法校验 | 否（运行时） |

未使用：外部付费数据 API、爬虫采集、第三方模型密钥、外部 CDN 资源。发布产物 `dependencies` 为空。

## 二、数据来源与授权

- 官方机构名称与公开查询入口网址（关务署、国际贸易署、食药署、标准检验局、防检疫署、NCC、赋税署、农业部）。
- 税则税率、SSG 触发量与累积量、货物税单位税额、行政规费金额：**均为结构真实的示例参数**，
  在系统内标记 `verify_status = needs_verification`，UI 与报告显式显示"待核验"徽章与核验警告，
  不可用于实际报价、报关或签约。
- 企业痛点素材来自团队访谈记录《企业出海案例访谈》，未包含可识别的企业名称、金额或合同信息，
  提交材料中不公开敏感数据。
- 演示产品（低糖燕麦饮、无糖气泡水、磁砖、路由器等）为虚构样例。
