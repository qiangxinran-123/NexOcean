# 知海 TradePilot · 核心引擎（千问办公交付件）

面向国内出海企业（一期主战场：中国台湾地区市场）的 B 端决策工具核心层。
回答三个硬核问题：**能不能进？要花多少钱进去？进去好不好卖？**

本目录是 PRD 中「千问办公负责核心业务逻辑」那一部分的可运行实现，与 ChatGPT 交付的前端毛坯房
（`../src`、`../dist`）共用同一套视觉规范与字段契约。

## 一句话架构

**规则优先，AI 为辅。** 准入结论与所有金额一律由规则知识库推导；大模型只把引擎结果写成人类可读
的摘要，且输出前必须通过「数字白名单」审计——文本里出现的每个数字都要能在引擎结果中找到，否则整段
作废并降级为确定性模板成文。

## 运行

```sh
node server.js            # 默认 0.0.0.0:8081，读 process.env.PORT / HOST
node --test tests/engine.test.mjs
node tests/api-smoke.mjs  # 自带起停服务端
node tests/ui-check.mjs   # 需 Playwright + 本机 Edge/Chrome，产出 docs/screenshots
```

无需 `npm install`：`dependencies` 为空，全部使用 Node 22 与浏览器原生能力。

## 双模运行（重要设计决定）

前端启动时探测 `/api/health`：

- **服务端模式**：走 `/api/*`，产品档案与评估记录持久化，运营后台覆写生效，LLM 网关可用。
- **本地引擎模式**：API 不可用时，浏览器直接 `import ./engine/index.mjs` 在本地计算，数据落
  localStorage。两种模式调用的是同一份引擎源码，因此**同一输入必得同一结论**，不存在前后端两套
  算法漂移的问题。

静态托管（纯 HTML 站点）与动态托管（Node 服务）可用同一份产物，无需分别构建。

## 功能与边界

| 模块 | 状态 | 明确边界 |
|---|---|---|
| F1-1 准入判断 | 已实现 | 不替代官方审批；缺字段/无匹配规则一律输出「无法判定」；判定顺序为禁止清单 → 事前核准 → 逐批/登录 → 有条件准许 |
| F1-2 法规变更监测 | 已实现（采集层为运营录入 + 模拟 feed） | 只处理公开官方来源，非官方消息被拦截并说明；未宣称已完成自动爬虫 |
| F1-3 标签文案合规 | 已实现（纯文本） | 一期不做包装图片 OCR；区分「命中」与「未检出」，未命中不等于合规；简体文案先做繁简归一再匹配 |
| F2-1 综合税负 | 已实现 | 课征顺序固定：关税 → SSG → 货物税 → 捐费 → 营业税；每行输出计算式；未计入项强制展示 |
| F2-2 SSG 监控 | 已实现 | 线性外推仅供风险感知；结果标注快照日期与「以海关实际公告为准」；无数据即返回 unknown，不借用邻近品类 |
| F2-3 多方案对比 | 已实现 | 仅反映税负与作业成本差异，不含仓配与通路毛利 |
| 模块 5 底座 | 已实现 | 知识库运营后台（覆写层 + 审计 + 一键重置）、产品档案、消息中心、报告导出、LLM 网关、强制免责 |
| F3 竞品情报 / AI 文案生成 / F4 完整看板 | 未实现 | 按 PRD 属 P1/P2 与迭代 2、3，本版不开放生成 |

## 数据诚实性约定

规则条目带 `verify_status`：`verified`（已人工比对官方原文）/ `needs_verification`（结构真实、
数值为示例，禁止作为报价依据）/ `skeleton`（仅骨架，系统一律不输出结论）。

当前种子库除机构名称、网址与制度框架外，绝大多数数值为 `needs_verification`。系统不会把未核验规则
伪装成已核验：只要结论依赖未核验规则，`verification.usable_for_quotation` 即为 `false`，页面与报告
同步显示核验警告。官方来源只登记公开查询入口，首页链接不表示已完成具体条款核验。

## 与 ChatGPT 原型的口径兼容

原型成本页有两组静态快照。本引擎在「手工税率 + 关闭扩展费项」模式下必须复现同样的数字，已写成
自动化断言（`tests/engine.test.mjs` 第 1 项）：完税价格 31920、关税 3192、营业税 1755.6、
综合税负率 15.5%；SSG 15% 情景下 4788 / 1995 / 9975 / 42495 / 31.25%。

差异只在方向上扩展：新增货物税、捐费、行政规费、口岸物流、报价缓冲带与来源绑定。

## 已知限制（不粉饰）

1. 规则库数值未经人工比对官方原文，当前只能用于流程演示，不可用于实际报价与报关。
2. 无自动采集：法规更新依赖运营录入，延迟窗口不可控。
3. 无登录鉴权与真正的企业数据隔离，`x-workspace` 头只是演示级分区。
4. 服务端 JSON 持久化在容器重启后丢失；Supabase 驱动已实现，待平台开通数据库能力后按环境变量自动切换。
5. 向量检索未接入，当前为 BM25-lite 关键词检索；对同义表述的召回弱于向量库。
6. 单一目标市场深度建库，其余市场为骨架。
